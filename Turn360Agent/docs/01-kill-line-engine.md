# 01 盈亏与斩杀线引擎 KillLineEngine

## 1. 模块目标

`KillLineEngine` 用来判断店铺的经营盈亏、回本压力、现金流安全性，以及是否进入财务斩杀线。它也要识别正向通过条件：如果账算得通、回本合理、现金流安全，就应输出可开、可继续或可优化的财务依据。

注意：它不是简单的保本线工具。勇哥判断“斩杀线”至少包含两件事：

1. 这家店当前财务是否能活。
2. 如果当前不能活，用户有没有能力把它救回来。

本模块负责第 1 件事，并为最终综合决策提供财务事实。

## 2. 勇哥直播间表格公式

用户提供的表格字段：

```text
面积(平)                 25
房租元/月                6666
支付方式(月)             6
押金                     6666
转让费/中介费            0
加盟/技术学习费          0
装修/广告                30000
设备                     0
首批物料                 5000

每月人工                 8000
水/电/杂费               2000
日常运营费用             0
毛利率                   0.55

建店成本                 81662
每日固定成本             555.53
日盈亏平衡点             1010.06
```

### 2.1 建店成本

```text
建店成本 =
  房租元/月 * 支付方式(月)
+ 押金
+ 转让费/中介费
+ 加盟/技术学习费
+ 装修/广告
+ 设备
+ 首批物料
```

代入表格：

```text
6666 * 6
+ 6666
+ 0
+ 0
+ 30000
+ 0
+ 5000
= 81662
```

说明：

- 建店成本是开店前和开店初期已经投入或必须支付的钱。
- 它不等于每月固定成本。
- 它不进入“日盈亏平衡点”的计算。
- 它用于判断沉没成本、回本压力和归零损失。

### 2.2 每日固定成本

```text
每日固定成本 =
  (房租元/月 + 每月人工 + 水/电/杂费 + 每月固定运营费用) / 30
```

代入表格：

```text
(6666 + 8000 + 2000) / 30
= 555.53
```

说明：

- 这是每天不开单也在流血的钱。
- 只包含经营期固定支出。
- 不含食材，因为食材通过毛利率体现。
- 固定运营费用要算进去，例如固定外卖推广预算、固定排名费、社群工具、SaaS、固定达人合作月费等。
- 平台抽佣、配送补贴、支付手续费这类随订单变化的费用，不放在固定成本里，见“有效毛利率”。

### 2.3 日盈亏平衡点

```text
日盈亏平衡点 =
  每日固定成本 / 毛利率
```

代入表格：

```text
555.53 / 0.55
= 1010.06
```

说明：

- 每天卖到 1010.06 元，只代表不亏不赚。
- 不是回本。
- 不是值得开。

## 3. 扩展公式

### 3.0 毛利率

很多用户不知道什么是毛利率，系统不能直接问一句“毛利率多少”就结束。必须能解释，并支持用食材成本反推。

```text
毛利 =
  营业额 - 食材成本

毛利率 =
  毛利 / 营业额

也就是：

毛利率 =
  (营业额 - 食材成本) / 营业额
```

如果按一天算：

```text
日毛利率 =
  (日营业额 - 日食材成本) / 日营业额
```

例子：

```text
一天卖 1000 元
食材用了 400 元

毛利 = 1000 - 400 = 600
毛利率 = 600 / 1000 = 0.6 = 60%
```

对用户的问法：

```text
你要是不知道毛利率，就告诉我：
一天卖多少钱？
一天食材大概用多少钱？
我给你反推。
```

注意：

- 食材成本只算直接材料，例如米面、肉、菜、奶茶原料、包装等。
- 房租、人工、水电不放进毛利率，后面单独算固定成本。
- 如果用户只说“毛利挺高”，不能采用；必须要数字。

### 3.0.1 有效毛利率

外卖店、团购店和强平台依赖店，不能只看食材毛利率。平台抽佣、配送补贴、支付手续费、包装费、满减补贴等都会吃掉利润。

```text
有效毛利 =
  营业额
- 食材成本
- 包装成本
- 平台抽佣
- 配送补贴
- 支付手续费
- 满减/红包/团购让利

有效毛利率 =
  有效毛利 / 营业额
```

如果按一天算：

```text
日有效毛利率 =
  (日营业额
   - 日食材成本
   - 日包装成本
   - 日平台抽佣
   - 日配送补贴
   - 日支付手续费
   - 日营销让利) / 日营业额
```

对用户的问法：

```text
如果你靠外卖或团购，我还得问：
平台抽几个点？
配送补贴一天多少？
满减红包一天让利多少？
推广排名一天烧多少？
包装一天多少钱？
```

计算优先级：

- 堂食为主：可先用食材毛利率，再单独算固定运营费。
- 外卖/团购占比高：必须用有效毛利率。
- 用户不知道平台费用：要求提供外卖后台截图或按品类默认区间估算，并标记低可信。

### 3.0.2 日常运营费用分类

| 类型 | 示例 | 进入公式方式 |
|---|---|---|
| 固定运营费用 | 固定排名费、固定推广预算、账号代运营月费、SaaS、社群工具 | 加入月固定成本 |
| 变动平台费用 | 平台抽佣、支付手续费、配送补贴、按单包装费 | 从毛利中扣除，形成有效毛利率 |
| 阶段性投放费用 | 开业达人探店、短期推广、团购冲榜、信息流投放 | 单独列为投放预算，计算投放后净利 |
| 老板自由支配营销 | 发券、送菜、加量不加价 | 计入营销让利，影响有效毛利率 |

日常运营费用不能被藏在“杂费”里。外卖店尤其要单独拆出来，否则保本线会被低估。

### 3.1 当前月净利润

```text
当前月净利润 =
  月营业额 * 有效毛利率
- 月固定成本
- 阶段性投放费用

月固定成本 =
  房租 + 人工 + 水/电/杂费 + 每月固定运营费用

月营业额 =
  当前日营业额 * 30
```

### 3.2 当前日利润

```text
当前日利润 =
  当前日营业额 * 有效毛利率
- 每日固定成本
```

### 3.3 保本达成率

```text
保本达成率 =
  当前日营业额 / 日盈亏平衡点
```

分档：

| 达成率 | 财务分档 | 说明 |
|---:|---|---|
| < 60% | 红：斩杀线 | 离保本太远，通常应止损 |
| 60% - 80% | 橙：重亏 | 必须结合经营者能力验证 |
| 80% - 100% | 黄：接近保本 | 可短期整改 |
| 100% - 120% | 绿：小赚 | 需要看回本周期和提升空间 |
| > 120% | 深绿：健康 | 进入优化和扩利 |

### 3.4 回本周期

```text
回本周期(月) =
  建店成本 / 当前月净利润
```

特殊处理：

- 当前月净利润 <= 0：回本周期为 `null`，状态为“无法回本”。
- 回本周期 > 24 月：判定为回本慢。
- 回本周期 > 36 月：判定为高风险，即使当前小赚也不建议加投。

### 3.5 目标回本日销

用于判断“想在 N 个月回本，每天要卖多少”。

```text
目标回本日销 =
  (月固定成本 + 建店成本 / 目标回本月数 + 月阶段性投放费用) / 有效毛利率 / 30
```

默认目标回本月数：

| 品类 | 建议回本月数 |
|---|---:|
| 摆摊/小吃 | 3 - 6 |
| 早餐/快餐 | 6 - 12 |
| 饮品/轻社交 | 8 - 15 |
| 正餐/火锅/烧烤 | 12 - 24 |
| 重装修社交餐饮 | 18 - 30 |

超过建议回本周期，需要提高风险等级。

### 3.6 剩余现金撑店月数

```text
剩余现金撑店月数 =
  可动用现金 / abs(当前月净利润)
```

如果当前月净利润为正，则不计算。

分档：

| 撑店月数 | 判断 |
|---:|---|
| < 1 | 立即止损或补充现金，但不建议盲目加投 |
| 1 - 3 | 只能给短期整改 |
| 3 - 6 | 可给 30 天计划 |
| > 6 | 有试错空间，但仍看能力 |

### 4.1 毛利率与有效毛利率来源优先级

1. 用户提供真实食材成本和营业额，反推毛利率。
2. 用户提供外卖/团购后台费用，计算有效毛利率。
3. 用户提供后台毛利率或平台利润表。
4. 品类库默认值。
5. 行业数据区间中位数。

禁止用户只说“我感觉毛利挺高”。必须追问或使用品类默认值并标记低可信。

外卖占比超过 30% 时，禁止只用食材毛利率下结论，必须补问平台抽佣、配送补贴、推广、满减和包装。

## 6. 财务风险规则

### 6.1 红灯

任一命中：

- 保本达成率 < 60%
- 当前月净利润 < 0 且现金撑店 < 1 个月
- 抵押房产/贷款/借亲友钱 + 当前亏损
- 月房租占月营业额 > 20%
- 平台推广/排名/满减导致有效毛利率低于 35%
- 外卖占比高但无法提供平台费用数据
- 回本周期无法计算且已开业超过 3 个月

### 6.2 橙灯

任一命中：

- 保本达成率 60% - 80%
- 现金撑店 1 - 3 个月
- 回本周期 > 36 个月
- 当前小赚但人工未计入老板工资

### 6.3 黄灯

任一命中：

- 保本达成率 80% - 100%
- 回本周期 24 - 36 个月
- 小赚但客流结构不稳定
- 平台推广费用占营业额过高，需要验证投产比

### 6.4 绿灯

全部满足：

- 保本达成率 >= 120%
- 月净利润为正
- 回本周期 <= 24 个月
- 资金来源没有高危债务

### 6.5 正向通过条件

满足以下条件时，财务层必须明确输出“财务上可以做/可以继续”，不能因为创业整体风险高而默认劝退：

- 建店成本在预算内，没有抵押房产、借亲友钱等高危资金结构。
- 日盈亏平衡点低于目标商圈可验证的同类店水位。
- 目标日营业额达到盈亏平衡点的 120% 以上。
- 按保守日销计算，回本周期在品类建议区间内。
- 月净利润覆盖老板合理工资或明确标注老板工资后的利润仍为正。

## 7. 与经营者能力联动

财务结果不能直接决定最终结论。必须传给 `FounderCapabilityEngine`。

联动规则：

| 财务状态 | 经营者能力 | 最终建议 |
|---|---|---|
| 红灯 | 任意 | 建议止损 |
| 橙灯 | < 40 | 建议止损 |
| 橙灯 | 40 - 60 | 7 天试运行 |
| 橙灯 | > 60 | 30 天整改 |
| 黄灯 | < 40 | 不给复杂运营，只给止损线 |
| 黄灯 | > 60 | 30 天整改 |
| 绿灯 | 任意 | 可以继续，进入扩利优化 |
| 深绿 | 能力达标 | 可以做/可以扩大，但仍需控制加投节奏 |

## 8. 归零计算器

当最终结论为“关店”时，触发归零表：

```text
已投入金额
- 可回收设备
- 可转让物料
- 可退押金
- 可能追回款项
= 预计归零损失
```

输出不应羞辱用户，只强调止损：

```text
这笔钱不能再用追加投资去救。
已经打水漂的认掉，剩下能拿回多少拿多少。
```

### 9.2 财务斩杀线测试

| 日营业额 | 期望 |
|---:|---|
| 500 | 红灯，保本达成率约 49.5% |
| 800 | 橙灯，保本达成率约 79.2% |
| 1000 | 黄灯，接近保本 |
| 1200 | 小赚，但需计算回本周期 |
| 2000 | 绿灯或深绿，明确输出“财务上可以继续/可优化” |

### 9.3 边界测试

- 毛利率为 0 时不得除零。
- 月净利润为负时回本周期为 null。
- 用户不知道毛利率时，应要求食材成本或使用品类默认值并标记低可信。
- 外卖/团购占比高时，应要求平台费用、推广费、满减、包装费，否则不得只用食材毛利率判断。
- 老板自己干活但未计工资时，应增加风险标记。
- 有贷款月供时，应加入现金流压力字段。
